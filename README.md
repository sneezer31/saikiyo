# さいきよ - 完全ローカルの短歌記録アプリ

「さいきよ」は、短歌を記録し、編むためのブラウザアプリです。
一般的なアプリとは異なる、いくつかの独自の思想（ルール）で動いています。

## 1. 誰にも覗かれない「完全な密室」
本システムは外部のサーバーと一切通信を行いません。入力したデータはすべてあなたの端末（スマホやPC）のブラウザ内部にのみ保存されます。運営側があなたの作品を勝手に覗き見ることは物理的に不可能です。

## 2. 「削除」の代わりに「アーカイブ」を
本作りに迷いはつきものです。そのため、データを完全に消し去る「削除」機能はあえて設けていません。不要になった作品は「アーカイブ」へ送ることで視界から隠し、必要な時にいつでも取り戻すことができます。

## 3. 「連作」は「リスト」で編む
テーマに沿った連作や、発表用のまとめは「リスト」という機能で管理します。複数の短歌を束ねて、順番を入れ替えながら推敲することができます。

## 4. 自分のデータは自分で守る（バックアップと自己修復）
完全な密室である代償として、クラウド同期のような自動バックアップはありません。ブラウザの履歴やキャッシュを消去すると、データも消滅します。
しかし、これは裏を返せば**「アプリの動作がおかしくなっても、キャッシュを消去すれば完全に新品の状態に直る」**ということです。以下の手順さえ覚えておけば、いかなる不具合も恐れる必要はありません。

* **日頃の備え：** 定期的にメニューの「脱出ターミナル」から、「完全脱出（データのダウンロード）」を行ってください。これが唯一の命綱です。
* **不具合が起きたら：** まず「完全脱出」でデータを手元に確保した上で、ブラウザのキャッシュ（Webサイトデータ）を消去してください。これでアプリは初期化されます。
* **復元：** 初期化されたアプリを開き、「完全救出」から先ほどダウンロードしたファイルを読み込ませれば、元通りになります。

## 5. 外部ツールとの連携（クリップボードへの一括出力）
さいきよは、あなたのデータを閉じ込めません。書き留めた複数の短歌を選択し、一括でクリップボードにコピーする機能を備えています。密室の推敲用デスクとして使い、最終的な連作の並び替えや画像化は別の専用アプリへペーストして行うなど、自由な連携が可能です。

### 導入手順（iPhone推奨）

1. 以下のURLをSafariで開いてください。
   `[ここにindex.htmlの実行URLを記載]`
2. 画面下部の中央にある「共有ボタン（四角から上向き矢印が出ているアイコン）」をタップします。
3. メニューから「ホーム画面に追加」を選択します。
4. ホーム画面に生成されたアイコンから起動してください。これであなただけの独立したアプリとして稼働します。
