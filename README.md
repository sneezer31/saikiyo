# さいきよ - 完全ローカルの短歌記録アプリ

「さいきよ」は、短歌や日常のメモを記録し、編集するための、非常にユニークなブラウザアプリです。
ダウンロードしてネットとつなげずに利用することもできます。
一般的なアプリとは異なる、いくつかの独自の思想（ルール）で動いています。

## 1. 誰にも覗かれない「完全な密室」
さいきよは外部のサーバーと一切通信を行いません。入力したデータはすべてあなたの端末（スマホやPC）のブラウザ内部にのみ保存されます。作者があなたの作品を勝手に覗き見ることは物理的に不可能です。

## 2. 「削除」の代わりに「アーカイブ」を
表現することに迷いはつきものです。そのため、データを完全に消し去る「削除」機能はあえて設けていません。不要になった作品は「アーカイブ（安心な削除）」へ送ることで視界から隠し、必要な時にいつでも取り戻すことができます。

## 3. 「連作」は「リスト」で編む
テーマに沿った連作や、発表用のまとめは「リスト」という機能で管理します。タグ付けによる強力な検索機能があり、複数の短歌やリストを束ねて、順番を入れ替えながら推敲することができます。

## 4. 自分のデータは自分で守る（バックアップと自己修復）
完全な密室であるかわりに、クラウド同期のような自動バックアップはありません。ブラウザの履歴やキャッシュを消去すると、データも消滅します。
しかし、これは裏を返せば**「アプリの動作がおかしくなっても、キャッシュを消去すれば完全に新品の状態に直る」**ということです。以下の手順さえ覚えておけば、不具合に対する備えとなります。

* **日頃の備え：** 定期的にメニューの「脱出ターミナル」から、「完全脱出（データのダウンロード）」を行ってください。これが命綱です。
* **不具合が起きたら：** まず「完全脱出」でデータを手元に確保した上で、ブラウザのキャッシュ（Webサイトデータ）を消去してください。これで、アプリと、記憶容量の5メガは初期化されます。
* **復元：** 初期化されたアプリを開き、「完全救出」から先ほどダウンロードしたファイルを読み込ませれば、元通りになります。

## 5. 外部ツールとの連携（クリップボードへの一括出力）
さいきよは、あなたのデータを閉じ込めません。複数の短歌を選択し、一括でクリップボードにコピーする機能を備えています。密室の推敲用デスクとして使い、最終的な連作の並び替えや画像化は別の専用アプリへペーストして行うなど、自由な連携が可能です。

### 導入手順の例（iPhoneの場合はSafari推奨）

1. 以下のURLをSafariで開いてください。
   `[ここにindex.htmlの実行URLを記載]`
2. 画面下部の中央にある「共有ボタン（四角から上向き矢印が出ているアイコン）」をタップします。
3. メニューから「ホーム画面に追加」を選択します。
4. ホーム画面に生成されたアイコンから起動してください。これであなただけの独立したアプリとして稼働します。
